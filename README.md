# DevFlash - For Web-Programming-Basic Class Project

A flashcard study site that organizes core web development concepts (HTML5 · CSS3) by week for quick review.
Built with pure HTML + CSS only (no JavaScript) — featuring 3D flip cards, category filters, and night mode.
